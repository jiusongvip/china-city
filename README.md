# China City 旅游建站框架

关键词：`china city`  
目标语种：英文  
站点定位：**China City Explorer**，一个交互式中国城市旅游决策中心，而不是又一篇静态“Top 10 cities”列表。

## 一句话结论

搜索 `china city` 的人真正需要的是“该去中国哪些城市、怎么选、怎么串联、怎么准备行程”。当前首页主要由 Wikipedia 城市列表、旅游媒体的静态城市榜单、重庆奇观报道和本地中餐厅站组成，信息虽多，但没有一个页面把“选择城市、比较城市、串联城市”做成可操作工具。我们要用 **城市筛选器 + 城市对比器 + 行程串联 + 月度/预算/高铁实用数据** 超越这些页面。

## 建站方向

1. 首页直接打 `china city`，同时兼顾 `cities in china`、`best cities in china`、`china city guide`。
2. 建立城市数据库页，首批覆盖 12-15 个核心城市，后续扩到 30+ 城市。
3. 提供四个高价值交互工具：城市匹配测验、城市对比器、行程串联器、预算/季节参考。
4. 用结构化数据、原创图片、月度天气/高铁信息、真实成本和 FAQ 建立 E-E-A-T 和长尾覆盖。
5. 上线后不断加城市页、对比页、路线页、季节页和签证/交通实用页。

## 关键判断

- 不做餐厅品牌词，不做只讲 Chongqing 的单点内容。
- 不复制 Wikipedia 的人口/行政区划大表，而是把城市数据翻译成旅行决策语言。
- 不依赖一次性榜单，而是让用户输入自己的旅行风格、时间、预算后得到个性化城市推荐。
- 每个页面只服务一个清晰搜索意图，内部用城市数据库共享数据，避免内容堆叠。
